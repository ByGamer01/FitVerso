## ✨ Visión General

FitVerso es una **app móvil multiplataforma** que transforma el entrenamiento físico en una **experiencia interactiva tipo RPG**.  
Inspirada en **Pokémon Go** y el universo **anime**, te permite moverte por el mundo real, ganar experiencia, desbloquear habilidades y competir contra otros usuarios.

Cada entrenamiento es una misión. Cada esfuerzo, un paso más hacia convertirte en el héroe de tu propio anime.

---

## 🎮 Características Principales

### 💪 Entrenamientos Gamificados
- Completa rutinas que otorgan **XP**, monedas y recompensas.
- **Sistemas de niveles y habilidades** al estilo RPG.
- Desbloquea **entrenadores anime** y aprende sus técnicas.

### 🧍‍♂️ Avatares y Personalización
- Crea tu **avatar anime** con estilo único.
- Mejora su nivel y equipamiento visual con cada logro.

### 📱 Onboarding Interactivo
- Una introducción tipo **historia anime**, donde eliges tu camino.
- Tutorial narrativo con voz, animaciones y energía.

### 🏆 Ranking Mundial
- Compite con jugadores de todo el mundo.
- Sistema de **leaderboard dinámico** actualizado en tiempo real.

### 🎥 Animaciones de Ejercicios
- Cada movimiento se representa con **animaciones anime 2D/3D**.
- Feedback visual inmediato al completar repeticiones.

### 🔥 Misiones Diarias y Eventos
- Desafíos especiales por tiempo limitado.
- **Eventos de temporada** con temáticas inspiradas en sagas anime.

## 🧩 Tecnologías Utilizadas

| Categoría | Herramienta / Framework |
|------------|------------------------|
| **Frontend** | Flutter (Dart) |
| **Backend** | Firebase (Auth, Firestore, Storage, Functions) |
| **Animaciones** | Rive / Lottie / Flutter AnimationController |
| **Diseño UI/UX** | Figma + Tailwind Tokens |
| **Gamificación** | Sistema de XP y niveles propio |
| **Estado Global** | Riverpod / Provider |
| **IA & Integración** | ChatGPT para generación de diálogos y misiones dinámicas |
| **Control de versiones** | Git + GitHub |

---

## ⚙️ Arquitectura del Proyecto

FitVerso sigue el patrón **MVVM (Model-View-ViewModel)** adaptado a Flutter, manteniendo un flujo claro entre datos, lógica y vistas.  
La estructura está diseñada para ser **modular, escalable y mantenible**, ideal para un equipo de desarrollo colaborativo.
